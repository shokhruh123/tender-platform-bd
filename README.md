## 🧩 Схема базы (6 таблиц)

```
company ──1:N──► tender ◄──1:N── tender_category
   │                │
   │ M:N            │ 1:N заявки          1:1 протокол
   ▼                ▼                       ▼
accreditation   application ──1:1──► victory_protocol
```

| Таблица | Строк | Назначение |
|---|--:|---|
| `company` | 12 | Организации: заказчики, поставщики, `both` |
| `tender_category` | 6 | Справочник направлений закупок |
| `accreditation` | 16 | Допуски компаний (M:N + уровень `basic/standard/premium`) |
| `tender` | 11 | Тендеры заказчиков |
| `application` | 19 | Заявки поставщиков |
| `victory_protocol` | 7 | Протоколы победы (1:1, составной FK гарантирует «свой» тендер) |
